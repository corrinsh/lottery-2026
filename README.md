# 大乐透 / 双色球 开奖数据研究（2026）

把中国体育彩票「超级大乐透」与中国福利彩票「双色球」2026 年已公布的开奖号码，做成可交互的走势看板。

> **声明：本项目只做公开开奖数据的记录与可视化，不含任何预测、推荐或投注建议。** 图表中的虚线是历史算术平均值，属描述统计，不代表未来结果。

## 在线查看

GitHub Pages 地址：**https://corrinsh.github.io/lottery-2026/**

进入后先选择「大乐透」或「双色球」，两者数据完全独立。

## 看板能做什么

- **总走势**：每期 7 个号码按第一位到第七位排好，一期接一期连成连续折线；折线会从第一个点逐点绘制到最后一个点。
- **第 1 — 第 7 位**：按位拆开，每个位次单独一张走势图，并标出该位次的全期均值。
- **悬停看数值**：鼠标移到任意数据点显示该期号码（总走势显示整期 7 个，单点视图只显示当前位次）。
- **期号查询**：输入期号自动缩放定位，并在下方列出该期完整开奖号码。
- **点击联动**：在图上点任意位置，下方立即显示那一期的 7 个号码球。

## 自动更新

`update.py` 每天 22:00 自动运行：

1. 抓官方最新公告，与本地期号比对（每次回溯最近约 200 期，某天漏跑会在下次自动补齐）
2. 只有出现新一期时，才重建表格、图表和看板
3. 校验最新期号确实写进了看板，防止「重建了但没生效」
4. 只把有变化的文件推送到 GitHub，Pages 随之自动重新发布

脚本不按星期判断开奖日，只认官网数据，因此春节、国庆等官方休市期间会自动跳过，无需维护假日表。

推送由 `sync_github.py` 走 GitHub API 完成（本机 `github.com` 的 git 通道不稳定），每个文件按原始字节算出 blob 哈希与远端比对，只上传真正变化的文件。Token 从仓库外的 `~/.workbuddy/secrets/github_token.txt` 读取，不入库。
